# Localzet SOCKS5

SOCKS5 TCP CONNECT-прокси на PHP и Localzet Server 7.x. Проект распространяется под GNU Affero General Public License v3 или более поздней версии.

[English documentation](README.md)

## Запуск

Нужны PHP 8.2+, CLI-расширения процессов/сети, требуемые Localzet Server, и Composer. Проверенная система — Linux.

```sh
composer install --no-dev
# Передайте SOCKS5_USERNAME и SOCKS5_PASSWORD через защищённое окружение сервиса.
php start.php start
php start.php stop
```

Настройки: `SOCKS5_BIND` (по умолчанию `127.0.0.1`), `SOCKS5_PORT` (1080), `SOCKS5_USERNAME`, `SOCKS5_PASSWORD`, `SOCKS5_MAX_CONNECTIONS` (1024 на worker), `SOCKS5_MAX_CONNECTIONS_PER_IP` (32) и `SOCKS5_MAX_ATTEMPTS_PER_MINUTE` (120). Без учётных данных запуск отклоняется. Явный `SOCKS5_ALLOW_NO_AUTH=1` разрешён только при привязке к loopback. Не открывайте анонимный прокси в публичную сеть. `SOCKS5_PID_FILE` и `SOCKS5_LOG_FILE` позволяют выбрать файлы состояния сервиса.

Аутентификация SOCKS по логину/паролю передаёт их открытым текстом. Используйте доверенную локальную сеть или аутентифицированный зашифрованный туннель; привязка интерфейса не заменяет сетевые правила доступа. Журнал не выводит содержимое пакетов аутентификации.

## Поддерживаемое поведение

TCP CONNECT к IPv4-адресам и DNS-именам. Handshake собирается из фрагментов TCP; объединённые пакеты аутентификации/CONNECT и ранние данные для relay сохраняются. Буфер ограничен 64 КиБ, установление соединения — десятью секундами. Ошибка подключения возвращает отказ SOCKS; успешный ответ содержит настоящий адрес и порт исходящего сокета.

UDP ASSOCIATE выключен в поставляемой конфигурации. Унаследованный обработчик экспериментальный, изоляция клиентов не проверена; для эксплуатации включать его не следует. BIND и IPv6-адреса назначения не реализованы и отклоняются. DNS пока блокирует worker; асинхронный resolver и политика доступа к назначениям остаются задачами эксплуатации. Одновременные подключения и частота попыток на IP ограничиваются настраиваемыми параметрами; подберите их под трафик и число процессов.

Изменены значения по умолчанию: loopback вместо всех интерфейсов, удалён фиксированный `user/pass`, анонимная аутентификация только по явной настройке, UDP не открывается безусловно. Перед обновлением проверьте конфигурацию сервиса. Реализация использует заявленную зависимость Localzet Server.

## Проверка

```sh
composer validate --strict --no-check-publish
composer install
composer run check
composer audit
```

Тесты поднимают временный прокси и локальный echo-сервер, проверяют фрагментацию и объединение handshake, ранние TCP-данные, relay, неверные учётные данные и запрет UDP/анонимного доступа. CI не развёртывает сервис и не публикует релиз. Лицензия — `LICENSE`.
