# Localzet SOCKS5

SOCKS5 TCP CONNECT-прокси на PHP и Localzet Server. Уведомления исходного проекта Walkor и лицензия MIT сохранены; изменения репозитория покрываются лицензией проекта.

[English documentation](README.md)

## Запуск

Нужны PHP 8.2+, CLI-расширения процессов/сети, требуемые Localzet Server, и Composer. Проверенная система — Linux.

```sh
composer install --no-dev
# Передайте SOCKS5_USERNAME и SOCKS5_PASSWORD через защищённое окружение сервиса.
php start.php start
php start.php stop
```

Настройки: `SOCKS5_BIND` (по умолчанию `127.0.0.1`), `SOCKS5_PORT` (1080), `SOCKS5_USERNAME`, `SOCKS5_PASSWORD`. Без учётных данных запуск отклоняется. Явный `SOCKS5_ALLOW_NO_AUTH=1` разрешён только при привязке к loopback. Не открывайте анонимный прокси в публичную сеть. `SOCKS5_PID_FILE` и `SOCKS5_LOG_FILE` позволяют выбрать файлы состояния сервиса.

Аутентификация SOCKS по логину/паролю передаёт их открытым текстом. Используйте доверенную локальную сеть или аутентифицированный зашифрованный туннель; привязка интерфейса не заменяет сетевые правила доступа. Журнал не выводит содержимое пакетов аутентификации.

## Поддерживаемое поведение

TCP CONNECT к IPv4-адресам и DNS-именам. Handshake собирается из фрагментов TCP; объединённые пакеты аутентификации/CONNECT и ранние данные для relay сохраняются. Буфер ограничен 64 КиБ, установление соединения — десятью секундами. Ошибка подключения возвращает отказ SOCKS; успешный ответ содержит настоящий адрес и порт исходящего сокета.

UDP ASSOCIATE выключен в поставляемой конфигурации. Унаследованный обработчик экспериментальный, изоляция клиентов не проверена; для эксплуатации включать его не следует. BIND и IPv6-адреса назначения не реализованы и отклоняются. DNS пока блокирует worker; асинхронный resolver, лимиты соединений/частоты и политика доступа к назначениям остаются задачами эксплуатации.

Изменены значения по умолчанию: loopback вместо всех интерфейсов, удалён фиксированный `user/pass`, анонимная аутентификация только по явной настройке, UDP не открывается безусловно. Перед обновлением проверьте конфигурацию сервиса. Импорты Workerman заменены на уже заявленную зависимость Localzet.

## Проверка

```sh
composer validate --no-check-publish
python3 tests/integration.py
```

Тесты поднимают временный прокси и локальный echo-сервер, проверяют фрагментацию и объединение handshake, ранние TCP-данные, relay, неверные учётные данные и запрет UDP/анонимного доступа. CI не развёртывает сервис и не публикует релиз. Лицензии — `LICENSE` и `MIT-LICENSE.txt`.
